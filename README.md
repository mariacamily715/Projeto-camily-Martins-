# Projeto de apresentação pessoal

Este projeto apresenta informações pessoais, uma foto, links para Instagram, TikTok e YouTube e uma tabela de preferências.

## Tecnologias utilizadas

- HTML5 para organizar o conteúdo da página.
- CSS3 para definir a aparência e ajustar a página para telas menores.
- Bootstrap 5.3.3, incluído pelo link CDN no arquivo HTML.

## Arquivos

- `index.html`: conteúdo da página.
- `style.css`: estilos da página.
- Imagens: foto e logos dos sites.
- `relatorio-explicacao.pdf`: explicação do projeto.
